# SuperPet

SuperPet 是一款基于卡牌对战逻辑的桌游引擎与模拟系统。本项目旨在提供一个高扩展性的游戏框架，支持复杂的卡牌效果解析、战斗模拟以及自动化测试。

## 🚀 项目特性

- **核心对战引擎 (`app/engine`)**: 包含完整的棋盘管理、回合控制、战斗结算及效果管理器。
- **卡牌解析系统**: 采用 JSON 格式定义卡牌（内功、招式、奇遇、事件），支持动态解析与加载。
- **仿真模拟器 (`sim`)**: 提供自动化对战模拟与数据分析工具，用于平衡性测试。
- **自动化测试 (`app/test`)**: 针对引擎核心逻辑的全面单元测试，确保系统稳定性。

## 📂 目录结构

```text
.
├── app
│   ├── engine       # 对战核心逻辑 (回合、战斗、效果等)
│   ├── sim          # 模拟器逻辑
│   ├── test         # 单元测试用例
│   └── ui           # 界面组件 (待开发)
├── cards            # 卡牌定义数据 (JSON)
├── sim              # 模拟报告与分析工具
├── artifacts        # 项目设计文档与美术素材
└── tasks            # 开发进度与任务看板
```

## 🛠️ 快速开始

### 环境要求
- Node.js (推荐 v16+)
- npm 或 yarn

### 安装
```bash
cd app
npm install
```

### 运行测试
```bash
npm test
```

### 运行模拟器
```bash
node app/sim/simulator.js
```
