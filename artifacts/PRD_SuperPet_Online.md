## 1. 产品定位

### 1.1 一句话定位
**100% 拟真的实体桌游在线版**——一款完全开源、免费畅玩的《超级宠物》在线平台，像素级复刻实体桌游体验，让玩家在线感受完整乐趣，为实体产品引流。

### 1.2 UI 设计总原则：100% 拟真

> 整个产品的 UI 设计核心只有四个字：**100% 拟真**。
>
> 玩家看到的不是"一个游戏界面"，而是一张真实的桌面——四位头戴兜帽披风、看不见面容的玩家，围坐在一张方桌周围。房间昏暗，头顶一盏射灯，只能看清桌面上的地图和配件，其他地方都被黑暗笼罩。**暗黑系视觉风格。**
>
> 棋盘是静态铺在桌上的纸，棋子是放在棋盘上的立体模型，骰盅是透明的玻璃盅，对战盘是彩色亚克力片——一切都和实体桌游一样。
>
> 没有进度条、没有弹出气泡、没有高亮光效、没有粒子特效。信息在固定信息栏中以文本形式展示，棋子在格子间一格一格移动，数值在计分器上翻动。
>
> **问自己：实体桌上会这样吗？如果不会，就不要做。**

**摄像机：** 位置固定（俯视桌面），但玩家可通过滚轮或双指缩放视角。手机版可按住画面在一定范围内左右旋转。

**3D 建模范围：** 除了游戏配件外，还需建模：
- 4位兜帽人（坐在桌边，面容不可见）
- 方桌
- 椅子（4把）
- 昏暗房间环境 + 头顶射灯

## 2. 用户故事

### Epic 1: 快速开局

**US-01: 创建/加入房间**
> 作为一位玩家，我希望快速创建或加入一个游戏房间，不需要注册账号。
- **等候大厅**：展示所有公开房间列表，**用图标代替文字**以省去本地化问题
  - 显示：当前人数（👤图标）、**玩家所在国家国旗**（🌐）帮助玩家选房时做判断
  - 有**创建房间**按钮
- **创建房间**：点击即生成房间，无需输入房间名
  - 系统分配 **4位 base36 房间码**（纯字母数字，不区分大小写，适合口头告知）
  - 自动生成进房链接 + 二维码
  - 可设为公开或私有
  - **公开房**：出现在等候大厅列表，任何人可点击加入
  - **私有房**：链接中带密码，不能从大厅通过输入房号进入。同样生成链接+二维码
- **加入房间**：公开房直接从列表点击或输入房号进入；私有房只能通过链接或扫码进入
- **房主权限**：
  - **无需凑满4人**即可点击"开始"
- **加入后即可开始语音/文字聊天**
- **开始后**，所有玩家投骰子决定跑圈顺序（高者优先。分数相同的再投一次，直到分出高下）
- 按跑圈顺序优先选择宠物

**US-02: 选择宠物**
> 作为一位玩家，我希望能从猫、狗、兔子、鹦鹉中选择我的角色。
- 按跑圈顺序，依次选择（前一人选完后下一人才能选择）
- 宠物**3D 模型放置在对战盘上**
- 点击宠物即表示选择：
  - 该组物件移动到选择者的面前方位置
  - **对战盘和一个宠物棋子**放入遮罩中（用于后续比武）
  - 天赋卡放在遮罩旁边
  - 另一个相同宠物棋子放置在地图上空的休整格中
- 轮到下一位玩家点击时，同样移到对应位置
- 一切模拟真实游戏场景

### Epic 2: 跑圈经营

**US-03: 物理摇盅**
> 作为一位玩家，我希望拿起透明的玻璃骰盅来回晃动，透过玻璃能看到骰子在盅内翻滚碰撞，停下来时看到最终点数。
- 鼠标/手指拿起骰盅 → 来回晃动 → **透明玻璃盅**，晃动时即可看到内部骰子碰撞翻滚
- 停下来时骰子静止，透过玻璃看到最终面数
- 骰盅动画在所有玩家屏幕上同步播放
- 骰子点数作为确定性输入广播给所有节点

**US-04: 棋子移动与棋盘交互**
> 作为一位玩家，我希望看到我的棋子沿着跑道逐格移动，走到哪格就知道触发了什么效果。
- 棋子带底座，在格子间**一格一格跳着移动**（非走路动画，像手推棋子在桌面上移动）每移动一格略停一下，并且有报数的音效
- 棋盘：**静态纸质感**，平铺在桌面上，无高亮、无特效、无发光
- 所有提示在**固定信息栏**中以文本形式展示，可滚动查看历史记录
- 棋子路过休整和比武格时，需要玩家选择前进的方向
- 信息栏内容示例：
  ```
  [系统] 猫 投骰子 → 4
  [系统] 猫 前进至 修炼格
  [系统] 猫 修炼：攻击+1，防御+1（当前攻5 防7）
  [系统] 狗 投骰子 → 2
  ```

**US-05: 管理手牌与修炼**
> 作为一位玩家，我希望看到我抽到的招式卡和内功卡，并能在修炼时使用内功卡。
- 手牌平时叠放在桌面上 
- 可选卡牌**浮空出现在玩家面前**，左右滑动可浏览所有卡牌。**此处可能是唯一不能100%拟真的地方**
- 点击一次 → 卡牌向上抽出一点（预览状态）
- 再点击 → 确认使用
- 机遇卡和事件卡中需要选牌的场景也都使用此交互效果
- 使用后计分器更新数值，信息栏显示变化

**US-06: 执行卡牌效果**
> 作为一位玩家，当我踩到机遇/事件格时，我希望看到卡牌效果并执行相应操作。
- 弹出卡面，显示卡牌名称和效果文字
- **无论是否涉及多人，所有玩家都能看到执行过程**
- 若需要选择，采用与修炼相同的浮空选牌交互（US-05）
- 效果执行后，属性/金币变化实时反映在计分器上，信息栏同步记录

### Epic 3: 比武对决

**US-07: 进入比武**
> 作为一位玩家，当有玩家踩到比武格时，我希望看到对战盘露出来。
- 触发者抽取一张比武卡
- **画面不切换**——**只是把覆盖在对战盘上的遮罩打开**，露出下方的对战盘
- **物理屏蔽罩**竖立在对战盘周围，遮挡来自两侧的视线
  - 每个玩家看不到对手的棋子，也看不到对手的位置和方向
  - 没有逻辑层的屏蔽计算——系统全知，只是渲染层不画对手棋子
  - 使用位置卡时，直接在棋盘上用不同颜色标记坐标
- 所有玩家在屏蔽罩内秘密选择初始位置和方向
- 所有人都完成后投骰子决定出手顺序（持有先手卡的强制第一位）
- **减少文字提示**：骰盅移动到谁面前，就表示该谁摇盅

**US-08: 出招攻击**
> 作为一位玩家，我希望能从手牌中选择招式，攻击可能在我攻击范围内的对手。
- 选择招式卡后确认出招（使用浮空选牌交互）
- 出招后：信息栏显示"猫 使用 前方锥形三格" + 命中结果
- 被击中的玩家：**计分器数值变化** + 信息栏提示 + 背景音效切换
- **棋子无震动、无闪烁、无特效**——100% 拟真
- 如果使用了天赋卡，则将其翻转

**US-09: 走位移动**
> 作为一位玩家，我希望在出招后能移动我的棋子到相邻位置，躲避对手下次攻击。
- 点击相邻格子确认移动
- 使用腾挪卡可以移动2格
- 移动后方向可重新选择

**US-10: 使用比武卡**
> 作为一位玩家，我希望能使用/购买闪避、反弹、位置卡等比武卡，并在适当时机获得提示。
- 商店面板可选购买项（**出招前**购买并使用）
- **出招前**可使用的卡：单人/全体位置卡、连击卡、腾挪卡
- **出招后/被击中时**被动触发：闪避卡、反弹卡（系统询问是否使用）
- 使用位置卡时，被查玩家的位置**在自己的棋盘上用不同颜色标记**（不闪烁）
- 使用全体位置卡时，所有对手位置同时标记

**US-11: 缩圈机制**
> 作为一位玩家，我希望看到对战盘逐步缩小，战斗越来越激烈。
- 每5轮，最外层对战盘以移除动画移除（像实体拿下那一层亚克力片）
- 处于被移除格子上的棋子自动回缩一格
- 信息栏提示："第5轮结束，外层战场移除"
- 第15轮后场地只剩中心1格，强制决战

### Epic 4: 结算

**US-12: 属性与金币变更**
> 作为一位玩家，我希望实时看到我的攻击力、防御力和金币的变化。
- 计分器以滚轮拨盘样式展示，数值变化时有过渡效果
- 永久属性（跑圈）和临战属性（比武）分两组展示
- 变化结果在**信息栏**中明确记录（无额外特效）

**US-13: 终局判定**
> 作为一位玩家，我希望游戏结束时看到最终的排名和统计数据。
- 终极比武结束后展示结果页面
- 以**表格形式**展示：
  | 玩家 | 攻击力 | 防御力 | 金币 | 获胜 |
  |---|---|---|---|---|
  | 猫 | 25 | 18 | 42 | ✅ |
  | 狗 | 20 | 22 | 8 | ❌ |
- 提供【退出】和【了解实体版】按钮
- 点退出，回到等候大厅
- 点了解实体版，进入众筹或产品购买页面

### Epic 5: 社交

**US-14: 语音聊天**
> 作为一位玩家，我希望在游戏中能和朋友们语音聊天。
- 进入房间后自动建立语音连接
- 支持麦克风静音/取消静音
- 显示谁在说话（头像高亮）

**US-15: 文字聊天**
> 作为一位玩家，我希望在游戏中能和朋友们打字交流。
- 聊天框位于界面底部
- 支持表情
- 游戏日志（系统消息）与玩家聊天在同一信息栏中

### Epic 6: 稳定性

**US-16: 断线处理**
> 作为一位玩家，如果有人掉线了，我不希望游戏直接报废。
- 检测到玩家掉线后，**30秒等待期**（倒计时显示）
- 等待期内掉线玩家可**重连回到原房间**
- 超时后掉线玩家被踢出房间，角色由 **AI 托管**
- AI 托管行为：
  - 跑圈阶段：自动物理摇盅 + 自动前进 + 自动修炼/抽卡（不使用内功卡） + 随机转向
  - 比武阶段：随机选择招式 + 向中心移动 + **可使用手上已有的比武卡**，但不主动购买商店卡
- 被踢出的玩家只能去**等候大厅**加入其他房间

### Epic 7: 运营统计

**US-17: 在线玩家统计**
> 作为玩家/运营者，我希望看到游戏平台的实时运营数据。
- 主页实时展示：
  - 当前在线玩家数
  - 今日累计游玩局数
  - 同时在玩的房间数
- 后台统计（运营可见）：
  - DAU / MAU
  - 平均游戏时长
  - 累计在线时长
  - 地域分布

## 4. 规则细节补充

### 4.1 开局流程
1. 房主创建房间（自动生成4位base36房间码 + 链接 + 二维码）
2. 设置公开/私有
3. 其他玩家加入 → 立即开始聊天
4. 房主随时点击"开始游戏"（无需凑满4人）
5. 所有玩家投骰子 → 排出跑圈顺序（高者优先，平局再投直到分出高下）
6. 按跑圈顺序依次选择宠物（点击后物件移到面前方）
7. 房主确定洗牌种子，全员同步
8. 游戏开始

### 4.2 比武卡使用时机

| 卡牌 | 使用时机 | 效果 |
|---|---|---|
| 单人位置卡 | 出招前购买并立即使用 | 标记指定玩家位置 |
| 全体位置卡 | 出招前购买并立即使用 | 标记所有玩家位置 |
| 连击卡 | 出招前购买并立即使用 | 本次出招连续两次 |
| 腾挪卡 | 移动阶段购买并立即使用 | 移动2格 |
| 闪避卡 | 被击中时系统询问 | 不受此次伤害 |
| 反弹卡 | 被击中时系统询问 | 攻击方受1/2伤害 |
| 先手卡 | 抽到即生效 | 比武时必定先手 |

## 5. 非功能需求

| 类别 | 要求 |
|---|---|

| **可扩展性** | 消息协议预留自定义字段 |
| **运营** | 主页实时数据 + 后台统计 |
